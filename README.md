# Терруар-калькулятор виноградника — демо

Интерактивный макет: оценка участка под виноградник по агроклиматическим
индексам (САТ, Хуглин, Уинклер, прохладные ночи, ГТК) с сортовой матрицей
и климатическими проекциями до 2100 года.
